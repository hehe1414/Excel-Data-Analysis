# Excel Data Analysis – Superstore Sales

**Task 5 – Excel Data Analysis**
Veda Technology | Data Analytics Track | Level 1, Day 5

## About
I analyzed the Sample Superstore dataset (2014-2017, 9,994 rows) in Excel using formulas, sorting, filtering and PivotTables. The workbook has three kinds of tabs so the raw data always stays safe.

## Workbook structure
| Tab | What it has |
|-----|-------------|
| Raw Data | The original data. I only added one helper column (Order Date Fixed) because some dates were stored as text |
| Working | SUMIFS, COUNTIFS and AVERAGEIFS formulas by region and category |
| Pivot tabs (5) | PivotTables, each answering one business question |
| Summary | Main KPIs (calculated with formulas) and a one-paragraph summary |

## Business questions answered with PivotTables
1. How do sales change month by month?
2. Which region sells the most?
3. Which category makes the most profit?
4. What are the overall KPIs?
5. Which sub-categories lose money?

## Key KPIs
| KPI | Value |
|-----|-------|
| Total Sales | 2,297,201 |
| Total Profit | 286,397 |
| Profit Margin | 12.5% |
| Units Sold | 37,873 |

## Key findings
- West has the highest sales (725,458) and South the lowest (391,722)
- Technology makes the most profit (145,455)
- Furniture has high sales (741,999) but only 18,451 profit, about 2.5% margin
- Tables and Bookcases lose money
